# AI Interview Preparation Application 

An AI-powered Interview Preparation Application built using **React, HTML, CSS**, and **Google Gemini API**. This application helps users prepare for technical and HR interviews by generating interview questions, providing AI-powered responses, and improving interview readiness.

## 📌 Features

- 🤖 AI-generated interview questions
- 💬 Interactive interview preparation experience
- 📝 Practice technical and HR interview questions
- ⚡ Fast and responsive user interface
- 🎨 Modern UI built with React, HTML, and CSS
- 🔐 Secure API integration with Google Gemini
- 📱 Responsive design for desktop and mobile devices

---

## 🛠️ Technologies Used

- **React.js**
- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **Google Gemini API**

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/AI-Interview-Preparation.git
```

### 2. Navigate to Project Folder

```bash
cd AI-Interview-Preparation
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the root directory:

```env
VITE_GEMINI_API_KEY=your_gemini_api_key
```

or

```env
REACT_APP_GEMINI_API_KEY=your_gemini_api_key
```

depending on your project setup.

### 5. Start Development Server

```bash
npm run dev
```

or

```bash
npm start
```

---

## 🔑 Gemini API Setup

1. Visit Google AI Studio.
2. Generate your Gemini API Key.
3. Add the API key to your `.env` file.
4. Restart the development server.
